**Goal:** Painel web do Arlequin ao lado do OpenCPN, com as 9 páginas da maqueta a funcionar com dados reais do SignalK, alarme AIS no servidor e simulador em tempo real.

**Architecture:** Webapp SignalK sem build (ES modules), com os cálculos puros em `public/lib` testados em node. O plugin `arlequin-ecra` dá as ordens de janelas. O plugin `signalk-arlequin-ais` reutiliza o `cpa.js` do ecrã. O simulador ganha `lib/navegacao.js`.

**Tech Stack:** Node ≥ 22, SignalK 2.33.0, `node:test`, WebSocket SignalK v1, API de notificações v2, `@meri-imperiumi/signalk-logbook` 0.13.2.

## Global Constraints

- Desenho: `docs/superpowers/specs/2026-09-29-ecra-roda-design.md`.
- Unidades SI em todo o lado; conversão só em `lib/formato.js` (pt-PT, vírgula, "—" sem dado).
- Limites AIS: CPA 0,5 MN, TCPA 20 min (`LIMITES_AIS`); histerese de limpeza 0,6 MN.
- Tamanhos em rem com `html { font-size: calc(100vh / 50) }` (serve 1280×800 e 1024×600).
- Noite: só variáveis CSS, e nada branco.
