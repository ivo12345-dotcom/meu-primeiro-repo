Política de privacidade

Quem trata os dados

O Rodado é uma aplicação de uso pessoal, instalada pelo próprio utilizador no seu telemóvel. Não existe qualquer servidor operado pela aplicação.

Que dados são recolhidos

Dados de atividade introduzidos pelo utilizador (turnos, despesas), relatórios de ganhos que o utilizador importe das plataformas de TVDE, e — quando o utilizador autorizar essa ligação — a leitura do odómetro e do histórico de carregamentos do seu próprio veículo Tesla.

Onde ficam guardados

Exclusivamente na área privada da aplicação, no telemóvel do utilizador. Os dados não são transmitidos para nenhum servidor, não são partilhados com terceiros e não são usados para publicidade ou análise.

Comunicações com o exterior

A aplicação comunica apenas com os servidores da Tesla, e apenas para obter os dados acima referidos, usando as credenciais de acesso autorizadas pelo utilizador.

Como apagar

Desligar a conta Tesla nas definições da aplicação revoga o acesso. Desinstalar a aplicação elimina definitivamente todos os dados guardados.
