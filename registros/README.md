# Registros de Navegação e Pesca

Diário de bordo e registo de capturas, organizados por saída.

## Organização

```
registros/
├── modelos/                    # modelos em branco a copiar para cada saída
│   ├── modelo-navegacao.md
│   └── modelo-pesca.md
└── AAAA/
    └── AAAA-MM-DD/
        ├── navegacao.md        # diário de bordo: rota, condições, motor
        └── pesca.md            # pesqueiros, artes, iscos e capturas
```

Cada dia tem a sua pasta. Os dois registos ficam separados (são dados
diferentes) mas juntos na mesma saída, para ser fácil cruzar *onde estive*
com *o que pesquei*.

Se um dia houver mais material — tracks GPX, fotos, cartas — entra na pasta
desse dia.
